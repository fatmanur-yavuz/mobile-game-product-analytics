# Mobile Game Player Retention & Level Churn Analysis

## Project Overview
This repository focuses on data-driven product analytics for mobile puzzle games, specifically analyzing player retention (Day 1, Day 7, Day 30), level completion drop-offs, and A/B test hypotheses to optimize core game metrics and monetization strategies.

---

## Core Focus Areas
* *Player Retention Analysis:* Tracking churn patterns and player drop-off rates across early-game levels.
* *Level Balancing & Difficulty Curve:* Identifying bottleneck levels that cause friction using statistical metrics.
* *Product Strategy Proposals:* Formulating data-informed hypotheses and LiveOps feature recommendations.

---

## Tools & Methodology
* *Data Processing:* Python (Pandas, NumPy)
* *Statistical Analysis:* A/B Testing, Hypothesis Testing (T-Test, Chi-Square)
* *Data Visualization:* Matplotlib, Seaborn
* *Product Frameworks:* Retention Funnels, Churn Root Cause Analysis

---

## Key Metrics Evaluated
* *D1 / D7 Retention Rate*
* *Level Completion Rate (%)*
* *Average Daily Active Users (DAU)*
* *ARPU / ARPPU Metrics Framework**
